# Tacos El Giro

Website for **Tacos El Giro** — authentic Mexican street food in the Tri-Cities,
featuring tacos, burritos, quesabirria, birria consomé, and fresh ingredients.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole site — every section, in order, top to bottom |
| `styles.css` | All the styling: colors, fonts, layout |

No build step, no dependencies. Open `index.html` in a browser and it works.

- [ ] **`price`** (24) — menu prices, currently `$—`
- [ ] **`phone`** (3) — phone number, in the header button, menu footnote, and Visit section.
      Update both the visible text and the `href="tel:..."`
- [ ] **`address`** (1) — street address in the Visit section
- [ ] **`hours`** (1) — open hours for each day
- [ ] **`maps-link`** (1) — "Get directions" button; paste a Google Maps link
- [ ] **`social`** (2) — Instagram and Facebook URLs

Also worth doing: swap the menu items for the real ones, and drop in real
photos of the food.

Once a value is filled in, the `data-todo` attribute can be deleted — it does
nothing but mark the spot.

## Publishing it (free, via GitHub Pages)

1. Merge this branch into `main`
2. Repo → **Settings** → **Pages**
3. Under *Source*, pick **Deploy from a branch** → `main` → `/ (root)` → **Save**
4. Wait a minute; the site appears at
   `https://neimiah12.github.io/Tacos-El-Giro-/`

A custom domain can be pointed at it later from that same Pages settings page.
